# Evidências dos laboratórios

Crie uma pasta por laboratório (por exemplo, `lab-01/`) e salve:
- diagrama/topologia;
- plataforma e versão da imagem;
- configurações sem segredos;
- saídas de comandos relevantes;
- capturas de tela quando úteis;
- testes de falha e recuperação;
- respostas dos exercícios;
- resumo de causa-raiz.

Não armazene credenciais, chaves privadas, dados de clientes, IPs sensíveis ou arquivos de produção.
