# Gabaritos comentados

Tente cada exercício antes de abrir o gabarito correspondente. O objetivo não é decorar comandos, mas justificar o resultado com evidências do plano de controle e do encaminhamento.

Cada arquivo de gabarito deve incluir:
1. Resposta direta.
2. Explicação do conceito.
3. Comandos para comprovar.
4. Resultado esperado.
5. Variações por plataforma.
6. Erros comuns e como reconhecê-los.

O gabarito do Módulo 01 está incluído no próprio [Módulo 01](../modulos/01-fundamentos-bgp/README.md).
