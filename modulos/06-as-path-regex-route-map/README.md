# Módulo 06 — AS_PATH regex, prefix-list e route-map

## Objetivos
Ler expressões regulares AS_PATH, compor políticas legíveis e reduzir erros de correspondência.

## Atividades
1. Monte uma tabela de AS_PATHs de exemplo.
2. Escreva expressões para identificar um ASN específico, rotas originadas por um ASN e caminhos que contenham determinado ASN.
3. Teste cada expressão contra casos positivos e negativos.
4. Compare filtro de prefixo com filtro de AS_PATH: cada um responde a uma pergunta diferente.
5. Aplique a política a um neighbor de laboratório e valide rotas aceitas/rejeitadas.

## Atenção
A sintaxe e a semântica das regex podem variar entre plataformas e versões. Documente o comportamento observado e consulte a documentação do equipamento. Não promova regex de laboratório para produção sem testes.
